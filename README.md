# Ozon Seller MCP

Неофициальный открытый навык и приватный MCP-сервер для работы с магазином Ozon через ChatGPT. Продажи, остатки, возвраты, поиск товаров по названию, цены, рейтинги и другие данные Seller API — обычными словами, только на чтение.

**Основной вариант: ваш VPS → личный ChatGPT Site → обычный чат ChatGPT Plus или Pro.** Установка использует режим «Работа», ежедневные запросы выполняются в обычном чате. Поиск товаров и чтение рейтинга проверены в обычном веб-чате Plus с подключённым магазином.

## Что можно спросить

- «Покажи продажи за неделю».
- «Какие товары заканчиваются на FBS? Порог — 3 штуки».
- «Найди именные выпускные ленты и покажи цены».
- «Проанализируй причины возвратов за месяц».
- «Покажи рейтинг магазина».
- «Какие отчёты и данные об отзывах доступны моему магазину?».

Для типовых задач есть готовые инструменты. Для остальных ChatGPT ищет метод в каталоге, получает схему параметров и запрашивает данные. Справочник API хранится на сервере и загружается по нужному методу.

## Установка

Понадобятся Linux VPS с Docker, домен с HTTPS, Client ID и API-ключ Ozon, аккаунт ChatGPT с доступом к Sites.

1. [Запустите приватный MCP на своём VPS](docs/SELF_HOSTING.md).
2. [Разверните личный плагин из шаблона Sites](sites/ozon-seller/README.md) и добавьте адрес MCP и его токен в серверные секреты Site.
3. Откройте новый обычный чат, выберите `@Ozon Seller` и напишите «Проверь подключение к Ozon».

Ключ Ozon хранится на VPS. Один экземпляр сервера и один личный Site обслуживают один магазин; каждый пользователь разворачивает своё подключение. OpenAI API-ключ для основного варианта не нужен.

## Возможности

| Инструмент | Назначение |
| --- | --- |
| `connection_status` | Проверка подключения и срока действия ключа |
| `sales_summary` | Заказанные штуки и сумма заказов по дням |
| `low_stock` | Остатки FBO/FBS за вычетом резерва |
| `returns_summary` | Причины, типы и товары возвратов и отмен |
| `product_price` | Текущая цена по артикулу продавца |
| `find_products` | Поиск по названию, артикулу, SKU, product_id или штрихкоду |
| `find_ozon_operations` | Поиск доступных операций чтения Seller API |
| `describe_ozon_operation` | Схема параметров выбранной операции |
| `read_ozon_operation` | Получение данных выбранным методом |

Каталог использует действующие роли чтения Ozon и набор проверенных методов. В рабочем подключении доступно 314 операций; состав зависит от ключа. Изменения товаров, цен, заказов и остатков блокируются сервером. Создание файлов отчётов и этикеток поддерживается для соответствующих методов чтения.

Доступность данных определяется правами ключа и условиями Ozon. Продажи в готовом отчёте — сумма заказов, а не прибыль или выплата. Ключи вводятся только в настройки сервера; Site остаётся доступным владельцу.
