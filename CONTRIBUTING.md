# Сообщения об ошибках и изменения

Текущий вариант проекта — приватный MCP на VPS, личный ChatGPT Site и девять инструментов чтения Seller API. Развитие проекта ведётся по конкретным задачам и сообщениям пользователей.

## Сообщить об ошибке

Создайте [issue](https://github.com/pdr086/ozon-seller-mcp/issues) и укажите:

- Какой результат ожидали и что получили.
- Шаги воспроизведения, инструмент или путь метода API.
- Режим подключения: VPS + Sites, прямой Site или локальный MCP.
- Версию кода или SHA коммита, клиент ChatGPT и тариф.
- Код ошибки и обезличенный пример параметров или ответа, если он нужен для воспроизведения.

Ключи Ozon, bearer-токены, email, адреса своего сервера и личные данные в issue не прикладывайте.

## Предложить исправление

Откройте pull request с описанием проблемы и получившегося поведения. Сохраняйте отдельные подключения магазинов, проверку владельца Site и ограничение на чтение. Права на выполнение метода определяет сервер, а не текст документации или ответ модели.

Проверка Python-кода с установленными зависимостями, Python 3.12:

```bash
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
```

Проверка Worker, Node.js 22 или новее:

```bash
cd sites/ozon-seller
npm test
```

Тесты используют вымышленные ключи и ответы и не требуют доступа к магазину.
