# Ozon Seller в ChatGPT Sites

Неофициальный плагин для Ozon Seller. Шаблон для одного магазина и одного владельца Site. Работает на чтение и обращается к Seller API напрямую. Отдельный VPS и OpenAI API-ключ для этой схемы не нужны.

## 1. Установите демо на аккаунте Plus

1. На компьютере войдите в ChatGPT под своим аккаунтом Plus. Откройте **Работа** и выберите `@Sites`. Скачайте архив этого шаблона. В чат приложите ZIP или, если ZIP недоступен, распакуйте и приложите `worker/index.mjs` и `README.md`.
2. Отправьте сообщение ниже. Дождитесь предварительного просмотра и разверните Site с доступом только владельцу. Секреты пока оставьте пустыми.

> @Sites Разверни новый личный Site «Ozon Seller — демо» из приложенного шаблона. Сохрани worker/index.mjs как исходный серверный Worker и при сборке скопируй его в dist/server/index.js. Добавь `"capabilities": ["mcp"]` в `.openai/hosting.json` и сохрани созданный для этого Site `project_id`. Отдельные базы и хранилища не нужны. Не меняй инструменты и правила доступа. Разверни приватно, только для владельца. Проверь, что Sites создал связанный плагин. Укажи описание «Неофициальный плагин для Ozon Seller. Продажи, остатки, возвраты и цены. Только чтение».

3. В каталоге **Плагины → Личные → Созданные вами** откройте плагин Site. Если есть кнопки **Установить** или **Подключить**, нажмите их. Затем на телефоне откройте обычный **Чат**, выберите плагин через `@` и напишите «Покажи продажи за неделю из демо Ozon Seller». Сервер должен вернуть **37 шт. и 12 490 ₽** с отметкой `synthetic_demo`.
4. В новом запросе «Проверь подключение к Ozon и скажи значение verified_sites_identity» инструмент в демо должен вернуть `verified_sites_identity: true`. Это показывает, что Sites передаёт проверенную личность владельца, нужную для работы с реальным магазином. Если плагин не виден или любой вызов не проходит в обычном мобильном чате, сохраните точный ответ и попробуйте обычный веб-чат для диагностики. Не подключайте магазин ради проверки доступности.

Создание и изменение Site на вебе использует режим «Работа» и соответствующий лимит. Для ежедневных запросов тестируется обычный чат. Возможность получать ответы из Sites на телефоне зависит от доступности плагина на конкретном аккаунте.

## 2. Подключите магазин после успешного демо

В **Sites → ваш Site → Настройки → Секреты** добавьте следующие значения. Используйте именно серверные секреты, доступные Worker. Не прикладывайте их к сообщению и не вставляйте в исходный код.

| Имя | Значение |
| --- | --- |
| `OZON_OWNER_EMAIL` | Адрес аккаунта ChatGPT, под которым вы установили плагин |
| `OZON_CLIENT_ID` | `Client ID` магазина в Ozon Seller |
| `OZON_API_KEY` | Ключ Seller API с правами на чтение товаров, аналитики и возвратов |

Сохраните изменения и при необходимости разверните Site заново. В обычном чате спросите «Проверь подключение к Ozon». Успешный ответ содержит `connected: true` и источник `ozon_seller_api`. Если заполнена только часть секретов, Worker останавливает вызов. Если Sites не передаёт подтверждённую личность владельца, Worker отклоняет доступ к магазину.

Не меняйте аудиторию Site на общедоступную. Каждый продавец создаёт свой Site и вводит свой ключ. Ключ передаётся только `api-seller.ozon.ru`, ответы содержат выбранные поля и агрегаты. При ограничении по страницам или времени инструменты остатков и возвратов отмечают неполный охват.

После подключения можно спросить «Какие товары заканчиваются?», «Проанализируй возвраты за неделю» или «Покажи текущую цену артикула ABC-123». Цена доступна по точному артикулу. Редактирование цен и других данных не входит в эту версию.
