# Личный плагин Ozon Seller в ChatGPT

Неофициальный плагин для одного магазина и одного владельца. Основной вариант: личный Site обращается к приватному MCP на вашем VPS. Все девять инструментов доступны в обычном чате; поиск товаров и чтение рейтинга проверены на аккаунте Plus.

## 1. Подготовьте MCP

Выполните [установку на VPS](../../docs/SELF_HOSTING.md). Подготовьте HTTPS-адрес MCP и значение `OZON_BRIDGE_TOKEN` из своего `bridge.env`.

## 2. Создайте личный Site

Войдите в ChatGPT под аккаунтом будущего пользователя плагина. Откройте режим **Работа**, выберите `@Sites` и приложите ZIP этого каталога. В архив должны войти `worker/`, `scripts/`, `package.json`, `README.md` и `.openai/hosting.json`.

Архив можно собрать из корня репозитория:

```bash
git archive --format=zip --output=ozon-seller-sites.zip HEAD:sites/ozon-seller
```

Отправьте сообщение:

> @Sites Разверни личный Site «Ozon Seller» из приложенного шаблона. Сохрани worker/index.mjs как исходный серверный Worker и при сборке скопируй его в dist/server/index.js. Используй capabilities: ["mcp"] из .openai/hosting.json, сохрани project_id созданного Site. База и хранилище не нужны. Сохрани инструменты, инструкции и проверки владельца. Подключение будет через приватный MCP: серверные секреты OZON_OWNER_EMAIL, OZON_MCP_URL и OZON_MCP_TOKEN. Разверни Site приватно, только для владельца. Проверь создание связанного плагина. Описание: «Неофициальный плагин для Ozon Seller. Поиск товаров, продажи, остатки, возвраты, цены и другие данные Seller API. Только чтение».

## 3. Добавьте серверные секреты

Откройте **Sites → ваш Site → Настройки → Секреты**:

| Имя | Значение |
| --- | --- |
| `OZON_OWNER_EMAIL` | Email аккаунта ChatGPT, который будет пользоваться плагином |
| `OZON_MCP_URL` | Ваш HTTPS-адрес MCP, например `https://ozon.example.com/mcp` |
| `OZON_MCP_TOKEN` | Значение `OZON_BRIDGE_TOKEN` с VPS, без префикса `Bearer` |

Client ID и API-ключ Ozon для этого варианта в Site не добавляются. Сохраните секреты и переопубликуйте тот же Site с доступом только владельцу. Worker проверяет подтверждённую личность пользователя и передаёт запросы на настроенный MCP.

## 4. Откройте обычный чат

В **Плагины → Личные → Созданные вами** откройте Ozon Seller. При необходимости нажмите **Установить** или **Подключить**, затем **Попробовать в чате**.

Начните новый разговор в режиме **Чат** с `@Ozon Seller`:

- «Проверь подключение к Ozon» — ожидается `connected: true`, `read_only: true`.
- «Найди товар по названию … и покажи его цену».
- «Покажи текущий рейтинг магазина».

В режиме VPS плагин предоставляет девять инструментов, перечисленных в [основном README](../../README.md#возможности). После обновления начинайте новый чат: открытый разговор может помнить прежний список инструментов.

На телефоне откройте тот же аккаунт и выберите плагин через `@` в обычном чате. Проверка этой установки выполнена в веб-версии Plus; доступность плагина в мобильном приложении зависит от клиента и аккаунта.

## Если подключение не отвечает

| Ответ | Что проверить |
| --- | --- |
| `incomplete_setup` | Заполнены все три серверных секрета |
| `owner_required` | Email владельца совпадает с аккаунтом; Site опубликован приватно и передаёт подтверждённую личность |
| `mcp_http_401` | Токен Site совпадает с токеном процесса на VPS |
| `mcp_unavailable` | HTTPS-адрес доступен, контейнер запущен, reverse proxy настроен |
| Только пять инструментов | Сохранены оба секрета `OZON_MCP_*`, опубликован актуальный Worker, открыт новый чат |
